Configuratie vereist
Stap 1 — Supabase project aanmaken
1. Ga naar supabase.com → New project → kies regio West EU (Ireland)
2. Kopieer in Project Settings → API uw Project URL en anon public key
3. Voer de SQL hieronder uit in de SQL Editor om de tabellen aan te maken
Stap 2 — SQL uitvoeren in Supabase
create table vehicles ( id uuid primary key default gen_random_uuid(), plate text unique not null, brand text, notes text, created_at timestamptz default now() ); create table events ( id uuid primary key default gen_random_uuid(), vehicle_id uuid references vehicles(id) on delete cascade, type text not null, subtype text, date timestamptz not null, location text, operator text, notes text, released timestamptz, video_url text, video_name text, photo_urls text[], created_at timestamptz default now() ); create table config ( key text primary key, value text ); -- Stel Row Level Security in op "open" voor dit privé-gebruik: alter table vehicles enable row level security; alter table events enable row level security; alter table config enable row level security; create policy "open" on vehicles for all using (true) with check (true); create policy "open" on events for all using (true) with check (true); create policy "open" on config for all using (true) with check (true); -- Maak storage bucket aan voor media: insert into storage.buckets (id,name,public) values ('media','media',true) on conflict do nothing; create policy "open media" on storage.objects for all using (bucket_id='media') with check (bucket_id='media');
